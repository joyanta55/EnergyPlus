Dockerfile
-------
**Pre-requisite** Make sure your `docker` runs in `rootless` mode. If you can run 
```
docker run hello-world
```
without `sudo`, you are good to go. 

Run the following command to build the docker image
```
docker build --no-cache -t energyplus .
```

To test

```
docker run energyplus -h
```
### To convert an IDF file located in `/tmp` directory

Create a folder to keep track of all the output generated by `energyPlus` image. 

```
mkdir -p /tmp/eplusout
```

Showing an example how `convert-only` flag of `energyPlus` can be applied on as /tmp/eplusoutny IDF file located in `/tmp`
directory. We need to mount the host `/tmp` directory where the IDF file is located. which we want to convert into epJSON format.

I copied one example from `testfiles/` directory. `1ZoneUncontrolled.idf` file. I copied that file to the /tmp directory. using `cp 1ZoneUncontrolled.idf /tmp` command. 

Then run the following command:

```
docker run --rm -v /tmp:/input -v /tmp/eplusout:/output energyplus --convert-only --output-directory /output /input/1ZoneUncontrolled.idf
```
and check the output at host `/tmp/eplusout` directory.

```
ls /tmp/eplusout
```
